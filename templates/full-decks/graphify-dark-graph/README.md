# graphify-dark-graph template source

This deck starts from the upstream html-ppt-skill full-deck template:
`templates/full-decks/graphify-dark-graph/`.

Upstream visual language retained:
- deep-night dark background
- drifting ambient orbs
- glassmorphism cards
- mono/display typography
- numbered slide chrome
- generous spacing and single-idea compositions

The deck adapts those structures into an interactive “Ai Là Triệu Phú” game.
